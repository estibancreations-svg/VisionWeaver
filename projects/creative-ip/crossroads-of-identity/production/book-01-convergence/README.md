# Book 1 — Convergence — Production

This folder tracks the video/episode adaptation of Book 1, chapter by chapter, as it moves through VisionWeaver. Each chapter = one episode. Source manuscript stays in Google Drive (source of record); this repo holds the versioned production decisions, prompts, and specs that come out of building each episode.

## Canon decisions locked so far
- **Marcus Reynolds relocated to Atlanta.** His law office and his condo are shown as Atlanta locations. Every other setting in the series (the safe house, Ybor City, etc.) stays Tampa, per the original manuscript.
- **Desiree's surname is Washington** (not Martinez — the Book 7 text used Martinez, which was an error; Washington is canon per the series index and is now locked).

## Process for building a location/backdrop
1. Identify the character's job/role and the type of space the scene needs.
2. Research real examples of that type of space — and, when a city is named, real architecture from that city — for grounding detail.
3. Build an **original** image inspired by that research. No real interior is copied or traced; no real building is reproduced exactly; no real firm or address is named in the artwork itself.
4. Document the research sources and the reasoning in this repo so the process is repeatable.

See `episode-01-the-news/` for the first worked example.
