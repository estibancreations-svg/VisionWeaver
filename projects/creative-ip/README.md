## VisionWeaver's role from here
This path is now an integration/pointer layer only. It may reference creative properties for orchestration, continuity, prompt generation and production workflows, but it is not the canon repository for either property.

## Rules
1. Original manuscripts/source conversations outrank production mappings.
2. Crossroads of Identity and This Is Your Life are separate canon universes.
3. Drive stores source manuscripts, artwork and binary production assets.
4. Dedicated GitHub repositories store manifests, production specs, continuity documents and versioned indexes.
5. Material marked `RECOVERY` is not silently promoted to canon.
6. VisionWeaver-generated material must link back to the correct dedicated repository/property.

Historical staging files remain here only as migration history and must not override the dedicated repositories.
