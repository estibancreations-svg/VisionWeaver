## Rules

1. Original manuscripts/source conversations outrank production mappings.
2. Crossroads of Identity and This Is Your Life are separate canon universes.
3. Drive stores source manuscripts, artwork and binary production assets.
4. GitHub stores manifests, production specs, continuity documents and versioned indexes.
5. Material marked RECOVERY is not silently promoted to canon.
