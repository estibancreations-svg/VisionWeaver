# VisionWeaver Standard: the 360 View Board

This file now points to the approved three-board character identity system. The full current rules are maintained in [character-board-system-v1.md](character-board-system-v1.md).

The default new character reference is a 32-view master: 8 eye-level azimuth views, 8 high-oblique views, 8 low-oblique views, and 8 extreme-oblique views. A 16-view state board is used for clothing-only or limited non-identity changes. The multi-character scene reference remains **A Cast Board**.
